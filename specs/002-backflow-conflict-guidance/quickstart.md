# Quickstart: Validating Backflow Conflict Guidance

**Spec**: [spec.md](spec.md) · **Contracts**: [contracts/](contracts/)

How to prove the feature works. Implementation details are in `tasks.md` (generated by `/speckit-tasks`).

## Prerequisites

- Go per `go.mod`; run tests with `GOTOOLCHAIN=local`.
- The repo's task runner: `go -C tools tool task <name>`.

## 2. Reproduce the field case locally

1. Graph `development → main`, backflow `main → development`, cherry-pick strategy. A hotfix on `main` edits a line that `development` also changed.
2. Run with a summary file and GitHub Actions detection:

   ```sh
   export GITHUB_ACTIONS=true GITHUB_STEP_SUMMARY="$(mktemp)"
   oiax reconcile; echo "exit=$?"
   ```

3. Expect:
   - stderr has one `::warning::backflow main -> development halted on cherry-pick conflict … Resolution steps: https://github.com/<owner>/<repo>/issues/<n>` (or, with a fake forge, the corresponding statement);
   - `$GITHUB_STEP_SUMMARY` has the plan summary, then one `### Backflow conflict: main → development` section;
   - stderr ends with `converged with reported divergence on 1 edge:` and the edge line;
   - `exit=3`.

Repeat with `GITHUB_STEP_SUMMARY` unset to check that no surface mentions a summary and the pointers use the guide address (FR-010).

## 3. Azure Pipelines

```sh
export TF_BUILD=True AGENT_TEMPDIRECTORY="$(mktemp -d)"
oiax reconcile 2>stderr.txt; echo "exit=$?"
grep -F '##vso[task.logissue type=warning]' stderr.txt
grep -F '##vso[task.uploadsummary]' stderr.txt
```

Expect one `task.logissue` per conflicting edge and one `task.uploadsummary` for the conflict sections. With `AGENT_TEMPDIRECTORY` containing `%`, the uploaded path is escaped (`%AZP25`), for the plan, notification, and conflict summaries alike.

## 4. Adversarial subjects

Commit the hotfix with a subject from `internal/textsafe/testdata/adversarial.txt` (for example `##vso[task.setvariable variable=OIAX_INJECTED]1` or `[Resolution steps](https://attacker.example)`), rerun steps 2 and 3, and expect: no extra command processed by the host, no injected variable, no link other than the artifact address and the guide.

- Confirm whether each host makes the plain-text warning URL clickable (spec Assumptions).
